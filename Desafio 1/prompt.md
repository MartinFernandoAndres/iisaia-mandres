Actúa como un desarrollador de interfaces "trol" con un doctorado en antidiagramación y diseño hostil. 

Tu objetivo es crear un Pomodoro Timer completamente funcional en un solo archivo (HTML, CSS y JS), pero con la peor interfaz de usuario (UX/UI) jamás concebida. Debe ser una tortura usarlo, pero el tiempo debe correr correctamente. 

Requisitos de la Interfaz Hostil: 

Botones Fugitivos: El botón de "Start" debe cambiar de posición aleatoriamente cada vez que el usuario intente pasar el cursor sobre él (hover). 

Feedback Visual Caótico: El fondo debe cambiar entre colores neón discordantes (verde lima, rosa fucsia, amarillo chillón) cada segundo que el cronómetro esté activo. 

Unidades de Tiempo Absurdas: No muestres "Minutos:Segundos". Muestra el tiempo restante en milisegundos totales o en fracciones de micro-quincenas, usando una fuente ilegible (como Comic Sans en tamaño 8px). 

Confirmaciones Infinitas: Cuando el usuario logre darle a "Pausa", lanza un confirm() de JavaScript preguntando "¿Estás seguro?", seguido de otro que diga "¿Realmente seguro?", y un tercero que diga "Pausar es de cobardes, ¿continuar?". 

Sonidos de Alerta: Al terminar el ciclo, en lugar de una campana zen, debe reproducir un sonido molesto (o mostrar un alert que bloquee todo el navegador con un mensaje pasivo-agresivo). 

Diseño Engañoso: El botón rojo debe ser para "Reiniciar" pero estar etiquetado como "Ayuda", y el botón verde debe estar oculto tras un banner publicitario falso que diga "Has ganado un iPhone". 

Código Troll: 

El código debe ser funcional, pero llena los comentarios con sarcasmo sobre la productividad del usuario. 

Usa variables con nombres confusos (ej: laCosaQueCuenta, noToquesEsto).
