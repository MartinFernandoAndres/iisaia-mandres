# TP1 - IISAIA

**Materia:** Inteligencia Artificial y Sistemas de IA Asistida (IISAIA)  
**Trabajo Práctico:** N° 1

---

## Descripción

Este repositorio contiene el Trabajo Práctico N° 1 de la materia IISAIA.

El proyecto consiste en un Pomodoro Troll (`pomotroll.html`), una aplicación web de temporizador tipo Pomodoro con una interfaz caótica y molesta a propósito.

## Archivos

- `pomotroll.html` — página principal del Pomodoro Troll

## Cómo usarlo

Abrir el archivo `pomotroll.html` en cualquier navegador web.
